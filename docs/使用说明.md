# 给翻译者的使用说明

这份说明面向使用软件的人，不涉及代码。开发相关的内容在 README 里。

## 这个软件是做什么的

它是一个逐句翻译工作台。机器翻译越来越顺，但在双关、行业行话、
文化潜台词上仍然会给出没错但不对的版本。真正需要拿捏分寸的地方，
还是得翻译者自己下笔。

LinguaTrans 不替你翻译，它做的是把原文清楚地摆到你面前：

- 从屏幕、PDF、视频里把原文一句一行取出来
- 用一个不挡视线的浮窗，上面原文，下面输入
- 你打完一句回车，自动跳下一句
- 最后把译文整理成 Word，原文图片放回原位
- 视频可以把你译好的双语字幕烧进画面

## 安装

到下载页拿对应系统的压缩包，解压即用，不用安装。

Linux 版需要系统里有 ffmpeg 和中文字体：

```
sudo apt install ffmpeg fonts-noto-cjk
```

Windows 版需要把 ffmpeg 放进系统 PATH，或者把 ffmpeg.exe 放在程序目录里。
ffmpeg 用于处理视频和音频，不做视频的话可以不管。

## 第一次使用

打开软件后先点环境自检，它会告诉你缺什么。
然后按你的材料类型选入口：

| 你的材料 | 选哪个 |
| --- | --- |
| 网页或屏幕上的文字 | 屏幕取词 |
| PDF 文档 | 打开 PDF |
| Word、txt、Markdown | 打开文本 |
| 带语音的视频或音频 | 打开视频 |
| 已经截好的图 | 屏幕取词里的导入图片 |

## 屏幕取词怎么用

点屏幕取词后会问你用哪种方式：

全屏识别：直接抓整个屏幕，把上面所有文字识别出来。
适合整页都是正文的情况，比如看一篇网页。

手动框选：屏幕上出现半透明蒙层，你拖一个框，只识别框里的内容。
适合正文只占屏幕一小块的情况，比如带侧边栏的网页。
框错了按 Esc 取消，重新框。

导入图片：如果你已经用系统截图工具截好了图，选这个导入。
Wayland 桌面下程序通常不允许直接抓屏，这时用这种方式最稳。

识别出来的文字会按行拆成一句一句，接着就能逐句翻译。

## 浮窗怎么用

浮窗做成桌面歌词的样子，不挡视线：

- 上面一行是原文
- 下面是输入框，直接打字
- 回车确认并跳到下一句
- 上一句下一句按钮可以回看
- 全部译完后浮窗会提示全部完成，可以回看修改

浮窗的位置、宽度、透明度都能在设置里调。
默认贴屏幕下方，如果你在看视频，可以改成上方，免得挡住字幕区。

## 视频字幕怎么处理

导入视频后会先用语音识别把每句话转写出来，带上时间轴。
识别在后台进行，界面不会卡住，长视频耐心等一下。

识别完你逐句翻译，然后选一种导出方式：

硬字幕：字幕烧进画面里。好处是任何播放器都能看，发给别人不用担心
对方没装字幕插件。代价是要重新编码，长视频耗时较久，画质有轻微损失。

软字幕：只生成 srt 和 ass 字幕文件，画质一点不损。
但需要播放器支持外挂字幕，把字幕文件和视频放同一目录、改成同名即可。

默认是硬字幕。想改的话在设置里切换。

## 语音识别模型怎么选

模型越大越准，也越慢。默认用 small，日常够用。

| 档位 | 体积 | 什么时候用 |
| --- | --- | --- |
| tiny | 约 75 MB | 先试试水，或者只是大概看看内容 |
| base | 约 145 MB | 语速平稳、录音清楚的访谈 |
| small | 约 480 MB | 默认，多数情况够用 |
| medium | 约 1.5 GB | 正式项目，要求准确 |
| large-v3 | 约 3 GB | 口音重、术语多、要求最高 |

模型不打进安装包，所以下载的压缩包不大。代价是第一次用某个档位
需要联网下载一次，之后存在本地，换档位才需要重新下。

## 字幕样式

中英两行的字号、颜色、离底边距离都能分别调。
默认英文白字在上、中文黄字在下，这是最常见的双语字幕排法。
调完可以先导一小段看看效果，满意了再处理整片。

## 项目文件

每导入一份材料会生成一个同名目录，里面有两个东西：

project.json 存着原文、你的译文、进度和时间轴。它是纯文本，
可以用任何编辑器打开，也可以备份、对比、放进版本库。
想手动改译文也行，改完在软件里重新载入。

assets 目录存 PDF 里抽出来的图片。导出 Word 时这些图会按原位置放回去。

关软件前不用特意保存，改动会随时写入。关掉再打开，接着上次的位置继续。

## 常见问题

识别出来的句子断得不好怎么办。
OCR 按行断句，遇到分栏排版可能串行。这时缩小框选范围，一行一行来。

视频识别出来是空的。
先确认视频里确实有人在说话。纯音乐、环境音是识别不出文字的。
多人抢话、口音很重的材料效果也会明显变差。

烧录很慢。
硬字幕必须重新编码，一小时视频大概要跑十几到几十分钟，
取决于机器性能。只要字幕不要重编码就用软字幕。

Wayland 下没法框选。
这是系统安全限制，程序抓不到屏。用系统截图工具截图后走导入图片。

识别结果里有错字。
语音识别对专有名词和数字容易出错，这是正常现象。
译文是你自己输入的，所以不影响最终质量，但看原文时要留意一下。

## 使用建议

正式项目用 medium 或更大档位，试水用 tiny 就好。
中文译文里人名、机构名第一次出现时，可以顺手在括号里保留原文，
方便后续统一。

浮窗适合逐句推进，如果你习惯先通读再翻译，可以先把整篇原文导出来看，
再回浮窗逐句处理。两种顺序都行，工具不限制。
