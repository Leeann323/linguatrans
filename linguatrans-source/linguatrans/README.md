# LinguaTrans 逐句人工翻译工作台

给翻译者和翻译作者用的辅助工具。它不替你翻译，而是把原文一句一句摆在你面前，
让你像看桌面歌词一样逐句输入译文，把多义、双关、风俗语这些机器翻不出来的东西
留给你自己拿捏。

## 它解决什么问题

机器翻译最擅长的是通顺，最不擅长的是分寸。文学里的双关、行业里的行话、
文化里的潜台词，机翻往往给出一个"没错但不对"的版本。翻译者要的是把原文
完整地看清楚，然后自己下笔。这个工具做的就是前半件事：

- 把屏幕上、PDF 里、视频中的原文原样取出来，一句一行排好
- 给你一个不挡视线的浮窗，上面是原文，下面是你打字的地方
- 打完一句回车，自动跳到下一句
- 译文按原顺序整理成 Word，原文里的图片原样放回原位
- 视频可以把你译好的双语字幕烧进画面，或者输出成外挂字幕

## 三种使用场景

### 文章模式

把一段英文正文取出来逐句对照翻译。原文来源可以是：

- 直接导入 txt 或 Markdown 文件
- 导入 PDF，正文和内嵌图片一起抽出来
- 屏幕取词，用系统截图工具截屏后导入图片，或者用浮窗的取词功能识别屏幕

浮窗会以桌面歌词的形式显示：上面一行英文原文，下面一行是输入框。
你打字，回车，下一句。

### 视频模式

导入一段没有字幕的英语视频或音频，程序用语音识别把每一句转写出来，
带上时间轴。你逐句翻译，可以边看边调时间点，最后选择：

- 硬字幕：字幕烧进画面，任何播放器都能看，画质有损，需要重新编码
- 软字幕：只生成 srt 和 ass 文件，画质无损，播放器需支持外挂字幕

### 校对模式

译文列表左边列出全部句子，已译的打勾，未译的留空圈。
可以随时点回去改任意一句，进度条显示整体完成度。
项目会随时保存，关掉软件再打开接着译。

## 安装

### 直接下载可执行文件

到 Releases 页面下载对应平台的压缩包，解压后运行。

Linux 版需要系统已装 ffmpeg，以及中文字体。以 Debian 系为例：

```
sudo apt install ffmpeg fonts-noto-cjk
```

Windows 版自带所需运行库，但视频功能同样需要 ffmpeg，
请把 ffmpeg.exe 放到系统 PATH 里，或者放在程序目录下。

### 从源码安装

```
git clone <仓库地址>
cd linguatrans
python -m venv .venv
source .venv/bin/activate        # Windows 用 .venv\Scripts\activate
pip install -e .
```

装完先自检：

```
linguatrans doctor
```

它会告诉你缺什么，并按提示装。

## 使用

### 图形界面

```
linguatrans
```

或者不帶参数直接运行，默认就是图形界面。

### 命令行

无界面环境或脚本调用时用命令行，功能与界面一致：

```
# 从文件提取原文，生成项目
linguatrans extract 文章.pdf
linguatrans extract 视频.mp4 --model small

# 导出译文 Word
linguatrans word 文章_linguatrans -o 译文.docx

# 导出软字幕
linguatrans subs 视频_linguatrans -o 字幕目录

# 烧录硬字幕
linguatrans burn 视频_linguatrans --video 视频.mp4 -o 输出.mp4

# 环境自检
linguatrans doctor
```

## 语音识别模型怎么选

模型档位决定识别准确率和速度，程序默认用 small，可以在设置里换。
首次使用某个档位会自动下载，之后走本地缓存。

| 档位 | 体积 | 适用 |
| --- | --- | --- |
| tiny | 约 75 MB | 最快，适合试水，准确率一般 |
| base | 约 145 MB | 快，日常够用 |
| small | 约 480 MB | 默认，速度与准确率较均衡 |
| medium | 约 1.5 GB | 较准，适合正式项目 |
| large-v3 | 约 3 GB | 最准，最慢 |

模型文件不打进安装包，所以安装包体积可控，代价是首次使用需要联网下载一次。

## 字幕样式

中英两行的字体、字号、颜色、离底边距离都能在设置里调。
默认英文白字、中文黄字，英文在上中文在下，这是最常见的双语字幕排法。
导出的 ass 文件里两种样式分别定义，用别的播放器打开也能保持。

## 项目文件结构

每导入一份原文会生成一个同名目录：

```
文章_linguatrans/
    project.json     原文、译文、进度、时间轴
    assets/          PDF 里抽出的图片
```

project.json 是纯文本，可以直接备份、比较、进版本库。
想手动改译文也可以，改完在软件里重新载入即可。

## 已知限制

- 屏幕取词目前是手动框选或整屏识别，还没有自动版式分析。
  网页和 PDF 的排版差别大，自动找正文容易出错，先用手动方式更稳。
- 语音识别对音乐、多人同时说话、口音重的音频效果有限。
  纯语音、单人讲述的材料效果最好。
- 硬字幕烧录会重新编码，长视频耗时较长，画质有轻微损失。
  追求无损请用软字幕。
- 识别结果需要人工校对，尤其是专有名词和数字。
  程序不会自动翻译，译文完全由你输入。

## 开发

```
pip install -e ".[dev]"
python tests/make_assets.py      # 生成测试用的图片、音频、视频
pytest tests/                    # 运行全部测试
```

测试分五层：内核、会话、识别、导出、界面。
界面测试在无头环境下用 offscreen 模式跑，验证控件构建与状态流转。
